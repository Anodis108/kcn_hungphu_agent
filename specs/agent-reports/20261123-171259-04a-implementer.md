## 1. Summary of Changes

Triển khai Phase 19.7 từ `specs/implementation-plan.md` trong phạm vi touch giới hạn (`touches: [resource/eval/batch.py, resource/eval/results/ (batch-* only), tests/test_*batch*]`):

1. **`resource/eval/batch.py`**:
   - Xây dựng script offline Batch API runner theo format OpenAI Batch API (`/v1/chat/completions`).
   - Hàm `build_batch_requests_from_dataset`: đọc YAML dataset cases, tạo danh sách requests chuẩn JSONL với custom_id, system prompt và user prompt. Hỗ trợ cờ `is_judge=True` để tự động build prompt cho LLM as a Judge.
   - Hàm `write_jsonl`: ghi requests ra file JSONL định dạng chuẩn UTF-8.
   - Hàm `get_batch_client`: khởi tạo OpenAI client lấy cấu hình primary từ `config/models.yaml` (hoặc fallback từ env settings qua `load_models_config`).
   - Hàm `submit_and_poll_batch`: upload input file lên provider (`purpose="batch"`), tạo batch job với endpoint `/v1/chat/completions`, polling định kỳ trạng thái, và khi hoàn tất thì tải kết quả về lưu tại `resource/eval/results/batch-<id>.jsonl`.
   - CLI flags: `--dataset`, `--output-dir`, `--judge`, `--dry-run`, `--model`.
   - Hỗ trợ `--dry-run`: build file JSONL trên đĩa, xác thực cú pháp và thoát exit code 0 mà không thực hiện bất kỳ cuộc gọi mạng nào.
   - Cách ly 100% offline (chỉ phục vụ eval/judge), không đụng chạm đến online graph, FE, hay database SQL batch.

2. **`tests/test_product_eval_batch.py`**:

     - `test_batch_main_dry_run_no_network`: kiểm tra CLI `--dry-run` chạy độc lập không mạng.
     - `test_submit_and_poll_batch_mocked`: kiểm tra toàn bộ luồng submit, polling loop và lưu kết quả với mock client.
