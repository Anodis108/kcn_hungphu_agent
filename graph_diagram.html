Pipeline tổng src/main.py

Guardrail input chặn cứng injection/nội dung độc hại trước khi câu hỏi chạm agent; câu hỏi ngoài phạm vi được trả lời lịch sự ngay, không gọi agent/DB. Guardrail output đối chiếu số liệu, redact PII, giới hạn độ dài trước khi trả về UI.

Agent ReAct graph src/agent/graph.py + react.py

LangGraph thật, xuất trực tiếp từ graph đã compile. Tối đa 2 lời gọi LLM/câu hỏi: agent chọn tool + tham số (function-calling, không Text-to-SQL tự do), pack gộp kết quả rồi answer.py (bên ngoài graph này, gọi từ _pack()) diễn giải thành câu tiếng Việt — có thể tắt qua ANSWER_USE_LLM=false.

Tool có sẵn cho LLM #1

6 tool tham số hoá trong src/agent/tools.py — model chỉ chọn tool + điền tham số, không tự sinh SQL (trừ fallback cuối).

get_db_schema Trả cấu trúc bảng/cột cho model tham khảo khi cần.
list_khu_vuc Liệt kê camera/khu vực hợp lệ, tránh model đoán sai giá trị lọc.
count_vehicle_flow Đếm lượt xe ra/vào theo thời gian, loại xe, hãng xe.
trace_plate Truy vết lịch sử di chuyển theo biển số.
zone_intrusion_by_hour Khung giờ xâm nhập khu vực nhiều nhất.
run_sql_readonly Fallback SQL đọc-only, whitelist bảng + chặn từ khoá ghi, dùng khi không tool nào khớp.
